# Card City website

Static site for [cardcity.com](https://cardcity.com), hosted on Netlify. Every change merged into `main` publishes automatically.

- **Update the payout guide:** replace `images/payout-guide.pdf` (same name, same folder). Both links on the site update on their own.
- **Edit the site:** content lives in `index.html`.
- **Contact forms:** handled by Netlify Forms (see the Forms tab in Netlify).

Rules for AI assistants (ChatGPT / Codex) are in [AGENTS.md](AGENTS.md).
